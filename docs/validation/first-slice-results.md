## 独立代码检查及修复

独立审阅指出四项重要问题，均补充失败测试后修复：

1. 关面板后旧场景仍能导入：关闭即清除缓存与显示；revision 不再重用。
2. 模型内构造未读取：先加载宿主持久化数据，未加载成功禁止保存，切换模型重读。
3. 取消成功与结果发布竞态：以同一任务状态锁保护取消受理和终态提交。
4. 旧浏览器无 randomUUID：使用 getRandomValues 实现 UUID v4。

另有光学元数据丢失、局部大坐标和错误材料输入的回归检查。

## 环境限制与未通过项

曾尝试用 Chromium 打开 RBZ 解压后的 file:// 页面，浏览器管理策略返回
`ERR_BLOCKED_BY_ADMINISTRATOR`。未绕过策略；改为验证同一归档的相对资源 HTTP 加载。
因此 HtmlDialog 的本地文件加载仍是未验证项，不能把 HTTP 成功当作它已通过。

系统默认 apt 快照域被网络代理拒绝；诊断工具改用临时配置里的官方 Debian 镜像，
保持仓库签名与包校验，没有改系统源或安装到系统目录。

## 本次实施决策

- 沿用隔离云工作区，切换功能分支，未新建 worktree。
- 技能脚本不在本机：以 /tmp 账本和本文记录执行证据，不伪造脚本执行。
- Windows 不可用时先完成独立引擎；任务 4/6 只记代码与可移植测试，不记实机完成。
- 独立服务先采用有上限的朴素 CPU 遮挡算法：最多 10,000 三角形，未来性能优化需重新测量。
- 首个交付使用人工导出/导入，不承诺已有后台即时联动。
- 无真实气象和审核条文时，界面保留待导入/待校核，不以示例阈值出结论。

上述决定的主要代价是旧宿主兼容性与大模型性能仍待后续验证；没有延后审阅已指出的重要缺陷。
