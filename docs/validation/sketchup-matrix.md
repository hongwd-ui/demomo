## 建议执行顺序

1. 安装开发 RBZ，记录签名策略与扩展加载结果；签名发布另行安排。
2. 使用独立测试模型，构造 1m 立方体、共享组件、镜像、非均匀缩放和嵌套编辑路径。
3. 开面板，编辑并保存构造，重开后验证名称、厚度和光学元数据不丢失。
4. 导出场景；核对单位、朝向、面标识、面积、原点和诊断，不跳过未确认真北。
5. 使用已编译的本地 worker 和显式太阳输入计算；导回当前模型，验证显示及清理。
6. 修改、撤销、重做、切换模型和关闭面板后导入旧文件，必须拒绝或要求重新导出。
7. 对比新版本 Overlay 与 2021 Tool 路径；检查用户当前工具和操作不被错误恢复。
8. 记录性能输入规模；当前单点直射预览不能作为完整太阳辐射或热工验证。
